## 依赖与性能

兼容版本更新前，npm 审计为 23 项：严重 1、高危 14、中等 2、低危 6。更新后为 11 项：中等 7、低危 4，高危与严重为 0。

生产依赖剩余 4 个低级告警来自 KaTeX 及其上游数学渲染依赖链（[GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7)）。另有 7 个中级告警位于 nodemon、TypeScript ESLint 和 minimatch 开发依赖链。没有采用 `npm audit fix --force` 提议的旧版数学插件降级；强制降级会破坏现有 Markdown/公式插件版本组合。`npm audit --omit=dev --audit-level=high` 通过，但本版不声称无漏洞。

非首页视图改为按需加载。构建中 Options 主入口约从 3.96 MB 降至 210 KB（未压缩，仅入口 chunk 对比，不是首屏全部资源总量）。图谱和编辑器的独立 chunk 仍超过 Vite 的 500 KB 提示阈值。

机械样式检查提示的两处上游风格（渐变标题、彩色区域内的灰色辅助文字）保留，本次未扩大到视觉重设计。上述窄屏验收主要覆盖列表和设置页，其余复杂工作区仍以桌面为主。

## 已完成但受限未验收

构建出的扩展包尚未加载到用户的真实 Chrome/Firefox。浏览器工具禁止访问 `chrome-extension://` 页面；因此离线浏览器测试使用源码测试入口、模拟扩展 API 和自建示例数据库，未使用已安装扩展的真实数据。

以下真实环境链路尚未验收：X 账号下的采集与平台近期 DOM/API 变化、用户 AI 服务商的接口/密钥/额度、浏览器长期休眠或强制中止正在执行的 AI 请求、真实目录授权和自动备份、Firefox 实际运行、十万级数据与大型 3D 图谱。

后台调度检查证明报警事件可重新调用两个队列，不代表所有浏览器终止场景和已中断 API 请求均已恢复。

## 使用与后续确认

按 README 加载 `dist_chrome`。从原版导出备份，到新版上传恢复；核对实际数量后再停用原版。新扩展数据空间独立，不会自动读取原插件的 IndexedDB。

GitHub Actions 包含类型检查、回归测试、Chrome/Firefox 构建、生产依赖高危门槛及打包产物上传。云端运行结果以仓库 Actions 页面为准。
