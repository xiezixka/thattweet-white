# Safari iPhone 版验收记录

日期：2026-11-14。版本：4.6.0。用户提供的目标系统：iOS 27.2。

状态：**已生成独立 Safari 资源，已在云端生成 Xcode 项目并编译模拟器应用；真实 iPhone 安装、Safari 运行和完整功能链路尚未验收。不可视为已完成真机交付。**

## 已通过

- TypeScript 类型检查；19 项自动化测试。
- Chrome、Firefox、Safari 三种构建；Safari 清单、HTML 资源引用、经典后台脚本语法校验。
- Safari 构建改为 MV3 默认非持久的经典后台页面，兼容 canvas。第二轮 Xcode 转换没有清单字段不支持警告，iPhone 模拟器应用编译通过。
- Apple 打包使用 `--ios-only --copy-resources`，生成独立宿主应用、扩展和资源副本。脚本拒绝覆盖已有 Xcode 项目。
- 运行时依赖审计的 high 阈值检查通过；仍有 4 个 low 等级 KaTeX 依赖告警，不宣称无漏洞。
- 本地受控示例页面在 390px 宽度检查了浅色画布、采集列表、触屏菜单、聊天/历史/笔记切换及设置入口。自动化浏览器的手机仿真坐标有偏差，部分按钮使用页面 DOM 点击，不能作为真实触控手势通过的证据。
- 创建两个示例会话、在第一会话写笔记、再创建第二会话后，第一会话笔记保留，第二会话为空，无页面脚本错误。
- 实际通过界面下载并重新解析示例完整备份：6 条推文、2 位作者、2 个会话，测试笔记保留，默认不含 AI 配置或 API Key。
- 自动化测试另覆盖：聊天和历史的无损序列化；无效文件拒绝；同 ID 冲突会话、独立笔记和历史版本保留；重复导入不重复创建相同冲突副本；旧备份不覆盖当前推文注释和已有手机 AI 配置；中断任务不自动计费重试；AI 服务按 HTTPS 域名授权。
- 电脑版安装目录仍为 4.5.7；与原 4.5.7 构建包逐一比较 113 个程序文件，变化数为 0。本任务没有操作电脑插件数据目录。

## 受限或未完成

- 本地真实文件导入后的整轮 UI 回读测试遇到测试浏览器下载权限提示；工具将控制权交给用户，尚不能把这个环节记为通过。已通过的备份结构和冲突合并测试不能代替端到端导入测试。
- 本机只有 Command Line Tools，无完整 Xcode、iOS 模拟器或可用的 Apple 签名环境。云端构建验证不能替代本机真机连接。
- 未在 iOS 27.2 真机签名安装，未验证真实 Safari 中 X 页面采集入库、DeepSeek/API 调用、OCR、语义检索、流式聊天、图谱和画廊、语音、锁屏恢复、真实「文件」导入导出或大数据内存占用。
- 应用保留全部既有功能入口，不代表 iOS 上所有链路均已确认正常。iOS 暂停策略不允许承诺持续后台采集和按分钟准时处理。
- 模拟器 `.app` 和资源 ZIP 不能直接安装到真实 iPhone；真机安装需要 Xcode、本人签名 Team、设备开发配置。TestFlight/App Store 分发另需相应 Apple 账号与流程。
- 没有读取或迁移电脑原版聊天、笔记，也没有停用任何电脑插件。原版普通 JSON 备份不包含聊天、笔记，不因本项目存在完整导出格式而自动补齐旧数据。
